# Anm 规则集

规则链接均指向 `Anm419/ios_rule_script` 仓库 `master` 分支下的 `Anm` 目录。

每行末尾的 `YouTube`、`OpenAI`、`Google` 是策略或策略组名称，请按你的配置修改。同一分类的普通版和 `_Resolve` 版选择其中一种使用即可。

## Loon

### 普通版

```ini
RULE-SET,https://raw.githubusercontent.com/Anm419/ios_rule_script/master/Anm/Loon/YouTube/YouTube.list,YouTube
RULE-SET,https://raw.githubusercontent.com/Anm419/ios_rule_script/master/Anm/Loon/OpenAI/OpenAI.list,OpenAI
RULE-SET,https://raw.githubusercontent.com/Anm419/ios_rule_script/master/Anm/Loon/Google/Google.list,Google
```

### _Resolve 版（可选替代）

```ini
RULE-SET,https://raw.githubusercontent.com/Anm419/ios_rule_script/master/Anm/Loon/YouTube/YouTube_Resolve.list,YouTube
RULE-SET,https://raw.githubusercontent.com/Anm419/ios_rule_script/master/Anm/Loon/OpenAI/OpenAI_Resolve.list,OpenAI
RULE-SET,https://raw.githubusercontent.com/Anm419/ios_rule_script/master/Anm/Loon/Google/Google_Resolve.list,Google
```

### China

`Anm/Loon/China/` 目前仅有占位文件，尚无规则文件，因此暂不提供 `RULE-SET` 条目。
